Understand the measurements +

A browser view of your connection

Latency is an HTTP request round trip, including browser and server processing. It is not ICMP ping. Failed HTTP requests are not a packet-loss measurement. Results reflect the path to the selected test endpoint.

Actual transfers, honest limitations

Download rates count received payload bytes. Upload rates count chunks acknowledged by the server, so brief upload chart spikes are not socket-level rates. Mbps uses decimal megabits; MB uses decimal megabytes. A limited budget may end phases early.

Keep this page active

Stability monitoring checks requests while the page is active. Background tabs, screen locks, and sleep can interrupt timing. Observation gaps are reported separately from failed requests.

Your history stays here

The app stores results locally in this browser and does not upload your saved history. Network tests contact Cloudflare, which receives your IP address and test requests. Payload budgets reserve bytes for requests, including failed attempts, and exclude protocol overhead.
